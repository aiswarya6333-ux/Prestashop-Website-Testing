# PrestaShop Website Testing

## Project Overview

PrestaShop is a demo e-commerce web application tested using Manual Testing and Selenium Automation Testing.

The project focuses on validating major e-commerce functionalities including Registration, Login, Product Search, Product Details, Shopping Cart, Checkout, and Order Placement.

## Application Under Test

**Application:** PrestaShop Demo Website

**URL:** https://demo.prestashop.com/

## My Role

**Manual & Automation Tester**

* Prepared test plan and test cases.
* Executed manual test cases.
* Identified and documented defects.
* Prepared test execution and summary reports.
* Automated selected test scenarios using Selenium WebDriver, Java, and TestNG.
* Implemented Page Object Model (POM) for reusable and maintainable automation.

## Automation Framework

The automation framework is developed using Selenium WebDriver, Java, TestNG, Maven, and Page Object Model (POM).

The Page Object Model approach is used to separate page elements and actions from test cases, improving code reusability and maintainability.

Cross-Browser Testing – Automated test execution across Chrome, Microsoft Edge, and Firefox browsers along with the POM framework.
